# 🌱 Consumindo Sustentabilidade e Incentivando Nossos Produtores

Uma página web desenvolvida para promover uma **Feira de Produtores Online**, conectando consumidores a produtores locais e incentivando práticas sustentáveis, o comércio justo e a valorização da agricultura familiar.

## 📖 Sobre o Projeto

O objetivo deste projeto é oferecer uma plataforma simples e atrativa para divulgar produtores locais, seus produtos e a importância do consumo consciente.

A página apresenta:

* Banner de apresentação da feira.
* Seção explicativa sobre a iniciativa.
* Cards com informações dos produtores.
* Botão de apoio aos produtores.
* Contador interativo de apoios utilizando JavaScript.
* Layout responsivo para diferentes dispositivos.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

## 🎨 Funcionalidades

### Página Inicial

Apresenta a proposta da feira e incentiva o consumo sustentável.

### Área de Produtores

Exibe produtores cadastrados em formato de cartões contendo:

* Nome do produtor
* Descrição dos produtos
* Imagem ilustrativa
* Botão de apoio

### Sistema de Apoio

Ao clicar no botão **"Apoiar"**:

* O contador de apoios é atualizado.
* Uma mensagem de agradecimento é exibida ao usuário.

## ⚙️ Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/feira-produtores.git
```

2. Acesse a pasta do projeto:

```bash
cd feira-produtores
```

3. Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar dependências ou executar servidor local.
